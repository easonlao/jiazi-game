## 游戏简介

在《甲子纪》中，你将扮演一位通晓天机五行运转的**修士**。

在六十甲子的轮回中，洞察季节更替的规律，通过纳灵、释灵"干支牌"来积累天命修为。

**每一张牌都是一次判断——什么时候纳灵，什么时候释灵，什么时候调息。**

## 核心玩法

### 🌸 四季轮回

春 → 夏 → 秋 → 冬 顺序循环，每季持续 4-12 回合（随机，段长总和恰好覆盖 60 回合，四季均衡）。

**季节影响卡牌价值**：
- 🌿 木属性：春天最值钱
- 🔥 火属性：夏天最值钱
- 🪙 金属性：秋天最值钱
- 💧 水属性：冬天最值钱
- 🪨 土属性：稳定型，所有季节都有小幅收益

默认交易规则下，卡牌在季内每 1–3 回合可能产生牌级评分波动，换季必然重新计算；公共区显示当前评分和相对基础评分的变化，手牌显示纳灵评分与当前评分。

### 💨 神识

"神识"是你唯一的交易筹码。上限 80，初始 50。

| 行动 | 神识消耗 | 说明 |
|------|--------|------|
| 纳灵 | 动态 | `ceil(11 × (1 + 0.005 × 评分))`；开燃灵额外 +8；纳灵占用部分神识（牵神），释灵时返还 |
| 释灵 | 0 | 释放该牌占用的牵神（受 80 神识上限截断），释灵本身不额外消耗神识 |
| 调息 | 0 | 下回合自然回复 10 神识，并额外回复 10 神识 |
| 炼化 | 每回合扣 | `ceil(max(0.5, 1.5 + 0.04 × 评分))`；燃灵仓位每回合额外 +`ceil(倍率 × 2)`（土牌为 `ceil(倍率 × 5)`） |

**神识归零且持有燃灵仓位时，触发反噬**：从燃灵仓位中移除「评分最高」的一张，该牌**无释灵收益**，直接承担反噬罚分 `round(燃灵 × |评分| × 3)`（修为可以为负），并返还一半牵神、牌回到公共牌堆。

### 🃏 卡牌系统

**60 张独特的甲子牌**，每张都有：
- 天干（甲乙丙丁戊己庚辛壬癸）
- 地支（子丑寅卯辰巳午未申酉戌亥）
- 五行属性（木火土金水）
- 阴阳属性

**每回合公共区展示 3 张牌，三丹田最多容纳 3 张。**

**卡牌锁定**：可锁定公共牌占位（每张每回合 -5 神识，上限 2 张），神识不足自动解锁评分最低的锁定牌。

### 📈 燃灵系统

季节越深入，燃灵档位越高；每季换季时重置。燃灵是可选项，纳灵时选择开启后，该仓位会跟随后续季内档位变化：

| 季节内回合 | 燃灵档位 |
|------------|----------|
| 1-2 回合 | 1.0x |
| 3-5 回合 | 2.0x |
| 6-8 回合 | 2.5x |
| 9-11 回合 | 3.0x |
| 12 回合 | 3.5x |

开启燃灵即使当前为 1.0x 也会建立燃灵仓位；后续档位按当前季内回合数升档。换季后燃灵仓位回到 1.0x，再随新季进度升档。燃灵放大收益，也增加炼化成本；神识归零时触发反噬！

### 🏆 胜利条件

**坚持 60 回合，积累最高修为！**

修为来源：
- **炼化收益**：每回合根据卡牌评分自动结算，`1.2 × 当季评分 × 燃灵`
- **释灵收益**：`(释灵时评分 - 纳灵时评分) × 6 × 燃灵`。纳灵释灵评分相同时为 0 修为

## 本地运行

**前置要求**：
- [Node.js](https://nodejs.org/) 22+（CI 与本地统一 Node 22 LTS）
- [pnpm](https://pnpm.io/) 9（与 CI 一致；`pnpm-lock.yaml` 是唯一 lockfile）

**步骤**：

```bash
# 1. 克隆仓库
git clone https://github.com/easonlao/jiazi-game.git
cd jiazi-game

# 2. 安装依赖
pnpm install

# 3. 启动开发服务器
pnpm dev

# 4. 打开浏览器访问
# http://127.0.0.1:5173
```

### 玩家身份与排行榜

游戏不要求复杂注册。玩家同意云端数据采集后会获得匿名玩家 ID，可设置显示名称并参与排行榜；跨设备找回身份需要保存创建时展示的一次性恢复码。玩家拒绝遥测或云端暂时不可用时，仍可继续本地游玩。

## 策略提示

1. **观察季节**：在春天纳灵木属性牌，夏天纳灵火属性牌，收益更高
2. **合理使用燃灵**：燃灵放大收益但也增加成本，神识不足时谨慎使用
3. **学会调息**：有时调息回复神识比强行纳灵释灵更划算
4. **注意炼化成本**：评分越高的牌，炼化成本也越高
5. **把握时机**：不要贪心，该释灵就释灵
