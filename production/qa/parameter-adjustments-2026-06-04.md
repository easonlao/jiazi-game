# 甲子纪 | MVP 核心数值参数调整方案 (2026-06-04)

## 1. 测试反馈与核心痛点分析
在 2026-06-04 的自动化场景模拟测试中，发现了两个关键的数值平衡痛点：
*   **痛点一：爆仓“无痛”且收益偏高**。当玩家因为持仓扣气导致当前气 `<= 0` 时，系统触发 `handleMarginCall` 强制平仓。由于强平不消耗气（免去 3 气消耗），且能 100% 获得卖出积分，激进策略无脑拉杠杆导致频繁爆仓（100局爆仓 20 次），却能凭借极高的杠杆刷分，均分（255.9）显著高于保守策略（196.7）。爆仓成为了一种主动止损和刷分的逃债手段，破坏了风险管理的趣味性。
*   **痛点二：保守策略气周转较慢，错失交易良机**。保守策略在气低于 40 时便进入等待，由于买入消耗（CB=12）和卖出消耗（3）的门槛限制，导致气周转效率低，频繁的被动等待使其错失了波段套现的黄金时间。

## 2. 机制调整：为强平引入折价惩罚 (Liquidation Penalty)
为了恢复“时机至上”与“仓位管理”的设计支柱，必须让强平行为付出代价：

### 2.1 合理性评估
*   **金融契约逻辑对齐**：强制平仓在现实金融中代表违约，违约须支付清算费用，资产以低于市场的折价变现。
*   **破除无脑杠杆策略**：引入收益打 8 折（0.8 系数）的惩罚，使频繁爆仓的期望收益降到稳健策略之下。
*   **防范“爆仓逃债”漏洞**：如果强平导致卡牌结算为负分（即高买低卖的亏损爆仓），不能直接打8折（否则会导致扣分减少，相当于变相免债）。必须采取“收益打折，亏损 100% 承担”的非对称惩罚机制。

### 2.2 机制实现 Diff (`src/core/TurnManager.ts`)
```typescript
      // 正常获得卖出分数（强平惩罚：正收益打 8 折，负收益 100% 承担）
      const currentScore = slot.card.getSeasonScore(this.seasonCycle.getCurrentSeason());
      const baseSellScore = this.scoreManager.calculateSellScore(
        currentScore,
        slot.buyScore,
        slot.leverage
      );
      const finalSellScore = baseSellScore > 0 ? Math.floor(baseSellScore * 0.8) : baseSellScore;
      this.scoreManager.addSellEarnings(finalSellScore);
```

## 3. 调参旋钮表微调 (Tuning Knobs Micro-adjustments)
为了给稳健/保守策略提供更好的气周转流动性，并拉开其与“被强平”的收益差距，我们对气系统的部分参数进行微调：

### 3.1 推荐调整参数对比表
| 参数符号 | GDD 名称 | 原设值 | 拟调整值 | 调优影响与设计意图 |
| :--- | :--- | :--- | :--- | :--- |
| `CB` | 基础买入消耗 | `12` | **`11`** | **降低准入门槛**：减少买卡时的固定消耗，使玩家在 30-40 气的紧张水位下，仍有开仓腾挪空间，盘活气周转。 |
| `CS` | 卖出即时回气 | `8` | **`9`** | **增强平仓激励**：主动卖出的净回气从 `8 - 3 = 5` 提升至 `9 - 3 = 6`。配合强平打折，形成强大驱动力：主动卖出能净回 6 气且得分 100%；被动爆仓回气 0 且得分打 8 折。 |

### 3.2 策略博弈趣味性分析 (主动卖出 vs 被动爆仓)
微调后，两种处理手牌的方式对比将变得极度鲜明：
1.  **主动平仓（Active Sell）**：消耗 3 气，结算 100% 卖出分，回补 9 气（**净赚 6 气**）。
2.  **强制爆仓（Margin Call）**：不消耗气，结算 80% 卖出分（若为亏损则 100% 扣除），回补 0 气（**净赚 0 气**）。
这极大地提升了玩家在接近爆仓边缘时的决策博弈深度：是硬扛一回合赌换季（可能面临零气连环爆仓，损失大量分数且无气回补），还是立刻主动变现保本并回气？这将使游戏的核心经济学魅力大增。
