# 盈亏结算系统

> 状态：Draft
> 层级：Core
> 优先级：MVP

## 概述

每回合自动计算玩家的分数变化，是游戏经济的结算引擎。将季节×五行的转化效率转化为具体数值，累计总分。持仓收益是持续性的，卖出收益是一次性的，两者共享同一套盈亏关系表。

## 玩家体验

玩家每回合开始时看到分数变动——涨了还是跌了，涨跌多少，一目了然。好的玩家能从分数跳动中感受到季节的力量：春天来了，木牌开始涨分；秋天来了，木牌开始扣分。这就是"时机"的直观反馈。

## 详细规则

### 结算时机

```
每回合流程中的位置：

1. 游戏结束检查
2. 季节检查（季节结束则切换）
3. ★ 盈亏结算（持仓收益）+ 持仓气耗扣除 + 爆仓检查
4. 刷牌（公共牌池展示）
5. 气回复
6. 玩家操作（买入/卖出/等待）
   └── 如果卖出：即时触发卖出结算 + 回复 8 气
```

> 持仓结算在季节切换之后、玩家操作之前执行，确保玩家看到的是当前季节的盈亏。卖出结算在玩家操作阶段即时触发，同时回复 8 气。

### 持仓结算（每回合自动执行）

```
对所有手牌：
  卡牌评分 = calcCardScore(卡牌, 当前季节)
    评分 = 天干季节共振 + 地支藏干根基 + 干支内部关系修正

  本回合盈亏 = HOLD_BONUS(1.2) × 卡牌评分 × 杠杆倍数
  如牌使用杠杆：盈亏 × 杠杆倍数
  总分 += 本回合盈亏
  本回合盈亏明细 = [{ 牌名, 属性, 评分, 得分, 杠杆倍率 }, ...]
```

> 卡牌评分采用“天干主动能量 + 地支藏干根基 + 当前季节环境场”的共振模型。评分不是卡牌好坏，而是该牌在当前环境下呈现出的状态强弱。

### 卖出结算（玩家主动触发时执行）

```
卖出评分 = calcCardScore(卡牌, 当前季节)    // 当前季节的卡牌评分
卖出得分 = (SELL_BASE(8) + (卖出评分 - 买入评分) × SPREAD_MULTIPLIER(4)) × 杠杆倍数
总分 += 卖出得分
即时回复 CS(8) 气
```

> 设计意图：买入时评分低（非当季），卖出时评分高（当季），差价为正则赚分。差价交易模型替代了原来的固定倍率表，让分数变化更平滑、更有层次感。

### 天干地支共振评分模型

游戏表达的核心不是“某个五行绝对好或坏”，而是万物在周期环境中显现不同状态。每张甲子牌由三层力量共同决定当下评分：

| 层级 | 传统来源 | 游戏含义 | MVP 权重 |
|------|----------|----------|----------|
| 天干 | 天之气，显于上 | 牌的主动能量，决定它“想往哪里走” | 0.6 |
| 地支藏干 | 地之气，藏于下 | 牌的根基与容器，决定主动能量落在什么环境里 | 0.3 |
| 干支关系 | 天地相交 | 内部顺逆，同气、生、泄、克带来的状态修正 | 0.1 |

```
最终状态分 =
  天干季节共振分 × 0.6
+ 地支藏干季节共振分 × 0.3
+ 干支内部关系修正 × 0.1
```

### 五行状态语义

五行不是固定属性克制表，而是一个周期中五种能量状态：

| 五行 | 状态语义 | 得势时 | 失势时 |
|------|----------|--------|--------|
| 木 | 生长、萌芽、发展、有方向性的力量 | 稳定向上，适合布局和扩张 | 方向受阻，成长迟滞 |
| 火 | 显化、传播、爆发、变化 | 短线爆发强，价值被看见 | 消耗过快，容易转衰 |
| 金 | 收敛、下降、冷却、成形 | 适合兑现、回收、落袋 | 压制成长，过早收缩 |
| 水 | 聚集、汇聚、收藏、蓄势 | 低位积累，等待下一周期 | 当前收益不显眼 |
| 土 | 太极点、承载、调和、环境镜像 | 随旺气显性，承接并稳定外部状态 | 缺少明确环境时平庸 |

### 五行关系语义

评分关系描述的是“状态是否顺势”，不是道德意义上的好坏：

| 关系 | 游戏含义 | 分数倾向 | 气耗倾向 |
|------|----------|----------|----------|
| 同我 | 有根、稳固、同频 | 稳定加分 | 较省力 |
| 生我 | 得资源、被供养 | 加分更稳 | 省力 |
| 我生 | 输出、显化、传播 | 收益提高 | 更耗气 |
| 克我 | 被压制、逆势 | 降分或负分 | 风险上升 |
| 我克 | 能控制环境 | 小幅收益或稳定 | 有额外消耗 |

> 后续实现应同时考虑“分数”和“气耗”两个结果：分数表示当下是否得势，气耗表示维持这个状态是否费力。

### 分数类型

| 类型 | 触发方式 | 频率 | 特点 |
|------|---------|------|------|
| 持仓收益 | 每回合自动 | 高频小额 | 稳定积累，长线策略核心 |
| 卖出收益 | 主动卖出 | 低频大额 | 集中爆发，短线策略核心 |

### 分数显示

| 显示项 | 说明 |
|------|------|
| 总分 | 累计得分，游戏核心指标 |
| 本回合盈亏 | 本回合持仓收益总和，带正负号 |
| 本回合明细 | 每张牌各自的盈亏 |
| 卖出得分 | 卖出时弹出的额外得分 |

### 分数规则补充

| 规则 | 说明 |
|------|------|
| 分数可以为负 | 持有对立牌或跨组牌会持续扣分 |
| 总分可以为负 | 不会重置为 0，负分就是负分 |
| 分数没有上限 | 理论上可以无限累积 |
| 游戏结束时最终总分 | 60 回合结束后，最后一回合正常结算持仓收益 |

### 干支内部关系修正

```typescript
function scoreStemBranchRelation(stemElement: Element, branchElement: Element): number {
  if (stemElement === branchElement) {
    return SAME_ELEMENT_BONUS;      // 同气有根，稳定
  }

  if (generates(branchElement, stemElement)) {
    return RESOURCE_BONUS;          // 地支生天干，根基供养显性能量
  }

  if (generates(stemElement, branchElement)) {
    return OUTPUT_BONUS;            // 天干生地支，输出显化，有收益也有消耗
  }

  if (overcomes(branchElement, stemElement)) {
    return PRESSURE_PENALTY;        // 地支克天干，内在环境压制主动能量
  }

  if (overcomes(stemElement, branchElement)) {
    return CONTROL_BONUS;           // 天干克地支，能控制环境，但维持更费力
  }

  return 0;
}
```

### 土的特殊规则

土不是“没有季节的第五属性”，而是太极点与承载器：

- **天干土（戊、己）**：主动表现为承载、调和、稳定，不追求最高爆发。
- **地支土（辰、戌、丑、未）**：作为容器和库，内部藏有其他气，能解释同为土而状态不同。
- **土在季节中显性**：当前环境旺什么，土就承接并显出相应倾向，但幅度低于该旺气本身。
- **土不应因四季无土而频繁为 0**：土牌至少应通过藏干、环境镜像、干支关系获得可解释状态。

### 持仓总盈亏

```typescript
function settleHoldScore(hand: (HandSlot | null)[], season: Season): SettlementResult {
  let roundScore = 0;
  const details: CardScoreDetail[] = [];

  for (const slot of hand) {
    if (!slot) continue;
    const { card, leverage } = slot;
    const score = calcCardScore(card, season);
    const earned = HOLD_BONUS(1.2) * score * leverage;
    roundScore += earned;
    details.push({
      cardName: card.name,
      element: card.mainElement,
      season,
      multiplier: HOLD_BONUS,
      score: earned,
      leverage,
    });
  }

  return { roundScore, details };
}
```

### 卖出得分

```typescript
function settleSellScore(card: HandSlot, season: Season): SellResult {
  const sellScore = calcCardScore(card.card, season);
  const score = (SELL_BASE(8) + (sellScore - card.buyScore) * SPREAD_MULTIPLIER(4)) * card.leverage;
  return { cardName: card.card.name, multiplier: SPREAD_MULTIPLIER, score, leverage: card.leverage };
}
```

### 爆仓强制卖出（使用相同卖出公式，不打折）

```typescript
function settleForcedSell(card: HandSlot, season: Season): SellResult {
  return settleSellScore(card, season);
}
```

### 单局总分模型（调参参考）

```
假设场景：玩家持有 1 张当季木牌（评分约 4-6），持续整个当季

  当季平均长度 = 7.5 回合
  持仓收益 = HOLD_BONUS(1.2) × 评分(约5) × 7.5 = 45 分

  如果当季末卖出（买入评分约 5，卖出评分约 5，差价约 0）：
  卖出收益 ≈ SELL_BASE(8) + 0 × SPREAD_MULTIPLIER(4) = 8 分

  单次完整操作总收益 ≈ 45 + 8 = 53 分

对比：非当季抄底买入（买入评分约 -2，等到当季卖出评分约 5）
  买入消耗 = CB(12) × (1 + 0.05 × (-2)) = 12 × 0.9 = 10.8 气
  持有跨组亏损 ≈ 1.2 × (-1) × 等待回合数
  等到当季持仓收益 ≈ 1.2 × 5 × 当季回合数
  卖出收益 = (8 + (5-(-2)) × 4) = 8 + 28 = 36 分

  效率取决于等待成本，风险更高但气消耗低，卖出爆发力更强
```

## 边界情况

| 场景 | 处理方式 |
|------|----------|
| 手牌为空 | 持仓结算结果为 0，本回合盈亏显示 0 |
| 手牌全部是对立牌 | 每回合持续大额扣分 |
| 手牌全部是高杠杆对立牌 | 每回合大额扣分且持仓气耗极高，快速爆仓风险 |
| 季节切换回合的结算 | 按新季节计算（季节检查在结算之前） |
| 最后一回合（第 60 回合） | 正常结算持仓收益，游戏结束 |
| 卖出得分为负（对立季节卖出） | 正常扣分，总分减少 |
| 总分为负时卖出正收益牌 | 总分回升，但仍是负分 |
| 多张牌同时持仓 | 各自独立计算，汇总后加到总分 |

## 调参旋钮

> ⚠️ 以下数值为设计目标。当前代码实现仍需后续对齐，所有参数最终应集中到配置或常量文件中。

| 参数 | 设计值 | 安全范围 | 影响 |
|------|--------|----------|------|
| HOLD_BONUS（持仓倍率） | 1.2 | 0.8 ~ 2.0 | 持仓收益整体放大系数 |
| SELL_BASE（卖出基础分） | 8 | 5 ~ 15 | 卖出得分的基础部分 |
| SPREAD_MULTIPLIER（差价乘数） | 4 | 2 ~ 8 | 买卖评分差价的放大系数 |
| STEM_WEIGHT（天干权重） | 0.6 | 0.5 ~ 0.75 | 显性能量对评分的贡献度 |
| BRANCH_WEIGHT（地支藏干权重） | 0.3 | 0.2 ~ 0.4 | 根基与容器对评分的贡献度 |
| RELATION_WEIGHT（干支关系权重） | 0.1 | 0.05 ~ 0.2 | 内部顺逆对评分的贡献度 |
| BASE_SCORE | 1 | 1（固定基数） | 所有计算的乘数基数 |

### 状态关系参数

| 关系 | 设计倾向 | 说明 |
|------|----------|------|
| 同我 | 稳定正向 | 有根，不必最高但应稳 |
| 生我 | 正向且省力 | 根基供养显性能量 |
| 我生 | 正向但耗气 | 输出、传播、显化 |
| 克我 | 负向或高风险 | 内在环境压制主动能量 |
| 我克 | 小正向但耗气 | 能控制环境，但维持费力 |
| 土环境镜像 | 温和随势 | 土承接当前旺气，幅度低于旺气本身 |

### 调参约束

| 约束 | 说明 |
|------|------|
| SELL_MAX > HOLD_MAX × 3 | 保证短线卖出有价值 |
| HOLD_MAJOR < -HOLD_MAX × 0.8 | 对立亏损要足够痛 |
| EARTH_NEUTRAL != 0 | 土牌必须有环境解释，不应因无土季频繁为 0 |
| RESOURCE_COST <= OUTPUT_COST | 被供养应比主动输出更省气 |
| PRESSURE_RISK > CONTROL_RISK | 被环境压制的风险应高于主动控制环境 |

## 验收标准

- [ ] 每回合自动结算持仓收益
- [ ] 卖出时正确计算一次性得分（差价模型）
- [ ] 卡牌评分由天干、地支藏干、干支关系共同生成
- [ ] 五行关系表达同我、生我、我生、克我、我克的状态差异
- [ ] 土作为环境镜像与承载点，不因四季无土而频繁为 0
- [ ] 分数与气耗可分别表达“是否得势”和“是否费力”
- [ ] 总分可以为负
- [ ] 分数变动有明细展示
- [ ] 季节切换按新季节计算
- [ ] 所有评分权重参数在配置或常量文件中可调
