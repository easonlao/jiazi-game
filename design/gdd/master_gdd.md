## 1. 游戏简介与核心幻想 (Overview & Player Fantasy)

### 1.1 电梯演讲
《甲子纪》（Jiazi Chronicle）是一款以**六十甲子**为主题的单人回合制策略卡牌经营游戏。玩家在春夏秋冬的随机季节轮回中，通过低吸高抛“干支牌”来管理仓位、积累分数。在 60 回合的倒计时中，“时机就是一切”。

### 1.2 核心幻想
玩家扮演一位通晓天机、五行运转的**命师**。在六十甲子的历史流转中，洞察季节更替的冷暖规律，通过买卖五行牌汇聚天命气场。
> **“什么时候进场，什么时候离场，什么时候按兵不动，是唯一的抉择。”**

---

## 2. 游戏设计支柱 (Game Pillars)

本项目的任何机制、数值和表现层迭代，都必须服务于以下 4 个不可妥协的设计支柱：

1.  **时机至上 (Timing is Everything)**：玩家的核心决策是“何时操作（When）”而非“操作什么（What）”。同一张牌，在春季买入与在秋季买入、在杠杆 1.0x 与 3.0x 时带来的结果截然相反。
2.  **信息不完全 (Imperfect Information)**：季节长度随机（3-12 回合），且总回合隐藏；牌池抽取存在随机洗回。玩家永远无法完美预测未来，只能基于概率和期望值做出有风险的决策。
3.  **简单规则，深度博弈 (Simple Rules, Deep Play)**：游戏没有繁杂的技能，仅有【买入/卖出/等待】三选一。但由于“手牌上限(3)”、“气上限(80)”与杠杆放大的持仓利息挤压，催生出极高的仓位管理与流动性博弈空间。
4.  **深刻的机会成本 (Severe Opportunity Cost)**：每回合仅能执行单一操作。做任一操作都意味着放弃其他两条路径。等待虽能回气，却会眼睁睁看着好牌流失并消耗掉 60 回合中宝贵的 1 轮生命周期。

### 反支柱 (What This Game is NOT)
-   **非数值养成游戏**：无卡牌等级强化，无局外数值增长，每局都是干净的 Roguelike 开局。
-   **非长线收集游戏**：卡牌是交易的“筹码”，不鼓励玩家将卡牌强制捏在手里到终局。

## 3. 核心循环与流程设计 (Core Loop & Turn Flow)

### 3.1 嵌套循环模型
-   **微循环 (30秒)**：观察当回合公共区 2 张牌 → 评估当前季节五行 → 做【买/卖/等】三选一。
-   **中循环 (3-12回合)**：在单季节周期内，抄底布局反季牌，拉满杠杆并在季节末尾高位套现。
-   **长循环 (60回合全局)**：在 60 回合倒计时中管理“气”资源池，追求总分最大化。

### 3.2 详细回合流程图 (7-Step Turn Sequence)

每回合开始到结束严格按照以下 7 个步骤串行结算：

```
[1] 游戏结束检查 ──> 若当前回合 > 60 ──> 进入游戏结束面板
       │
[2] 季节检查 ──> 若本季回合达到随机长度上限 ──> 重置子回合，切换为下个季节
       │
[3] ★ 持仓结算 ──> 计算 3 格手牌中每张牌在当前季节的评分，结算 HOLD_BONUS 并扣除持仓气耗
       │
[4] ★ 爆仓检查 ──> 若扣气后“气 <= 0”且持有杠杆牌 ──> 逐张强平（Forced Sell）直至气 > 0 或无杠杆牌
       │
[5] 刷牌 ──> 从牌堆中抽取 2 张牌展示在公共区。若牌堆已空则不展示
       │
[6] 气回复 ──> 气自然回复 QR(7)。若上回合动作为“等待”，额外回复等待加成 WR(10)
       │
[7] 玩家决策 ──> 三选一（买入其中 1 张 / 卖出手牌中 1 张 / 等待），执行后当前回合数 +1
```

## 4. 子系统详细规格说明 (Subsystem Specifications)

### 4.1 季节循环系统 (Season Cycle)
-   **流转顺序**：春（木） → 夏（火） → 秋（金） → 冬（水） → 循环。
-   **随机季节长度**：每个季节持续 3-12 回合（游戏初始化时预先随机生成所有季节长度列表，确保总和填充 60 回合）。
-   **信息可见度**：界面仅展示 `当前季节` 与 `本季已持续回合数`（例如：春 (第3回合)）。隐藏本季的总回合长度，玩家需要根据 3-12 的安全区间自行评估换季风险。

### 4.2 气资源系统 (Qi Resource)
气是命师的交易筹码，其流转构成了游戏的核心经济学。

-   **基础参数**：上限 80 气，初始 50 气。不可溢出。
-   **气回复机制**：
    *   **自然回复 (QR)**：每回合开始时自动回复 7 点。
    *   **等待奖励 (WR)**：上回合执行“等待”操作，本回合额外回复 10 点气（即总共回复 17 点）。
    *   **卖出即时回复 (CS)**：卖出卡牌时，卖出操作立即完成并回补 8 点气（可在同一回合用于防范持仓气耗）。
-   **气消耗机制**：
    *   **买入消耗**：`CB(12) * (1 + 0.05 * 买入时评分)`。高分当季牌贵，低分反季牌便宜。使用杠杆买入时，需额外支付固定消耗 `LQC(10)`，不乘以杠杆倍数。
    *   **持仓气耗（每回合）**：`Σ max(0.5, 1.5 + 0.4 * 当季评分) * 杠杆倍数`。
    *   **卖出消耗**：固定 3 点气。

#### 🌿 蛰伏低耗机制 (Taichi Low-Cost Settle)
当卡牌在跨组或对立季节时，由于评分跌为负数（如评分 `-3`），气耗计算结果 `1.5 + 0.4 * (-3) = 0.3`。此时会触发 `max(0.5)` 的保底机制。
> **设计目的**：允许玩家以极低的气息成本（保底 0.5 气）扛仓捏着亏损牌，度过非当季的寒冬，等待季节反转实现爆发。

### 4.3 卡牌与五行系统 (Jiazi Cards & Wuxing)

游戏由 60 张独特的甲子牌组成。每张牌天干地支五行映射如下：

#### 4.3.1 天干五行与属性映射 (10 天干)
天干决定卡牌的**主五行属性**，决定其主盈亏曲线：
- **木**：甲 (阳木/🟢绿)、乙 (阴木/🟢浅绿) — 春季最值钱
- **火**：丙 (阳火/🔴红)、丁 (阴火/🔴橙红) — 夏季最值钱
- **土**：戊 (阳土/🟤黄)、己 (阴土/🟤土黄) — 全季节稳定小幅正收益
- **金**：庚 (阳金/⚪金/白)、辛 (阴金/⚪银白) — 秋季最值钱
- **水**：壬 (阳水/🔵蓝)、癸 (阴水/🔵深蓝) — 冬季最值钱

#### 4.3.2 地支藏干五行映射 (12 地支)
地支藏干作为**副五行属性**，通过加权影响卡牌最终评分：
子 (水) | 丑 (土) | 寅 (木) | 卯 (木) | 辰 (土) | 巳 (火) | 午 (火) | 未 (土) | 申 (金) | 酉 (金) | 戌 (土) | 亥 (水)

#### 4.3.3 五行与季节圆盘关系表 (Wuxing Matrix)
同组内永远正收益，跨组亏损，对立亏损最大：
- **同组（顺时针相邻）**：木火一组，金水一组。
- **对立（180度冲突）**：木↔金、火↔水。
- **跨组（其他关系）**：木↔水、火↔金。

---

### 4.4 公共牌池系统 (Card Pool)
-   **牌堆大小**：初始 60 张，游戏开始前洗牌（Fisher-Yates 算法）。
-   **抽牌规则**：每回合从牌堆抽出 2 张置入公共展示区。
    *   若玩家选择买入 1 张，未选的 1 张洗回牌堆的**随机均匀分布位置**（不回到牌堆顶，防止预判）。
    *   若玩家选择卖出或等待，展示区的 2 张全部洗回牌堆随机位置。
-   **牌堆耗尽**：若牌堆仅剩 1 张，只展示 1 张。若牌堆为 0，公共区为空，玩家只能执行等待或卖出操作。

#### 🔮 Alpha 特殊牌（空亡牌）扩展预留
- **效果**：从公共展示区抽出时即时触发，不进入手牌，强制跳过本回合玩家操作阶段，并立即将当前季节长度随机加速推进 3-6 回合。
- **数据规范**：卡牌定义中预留 `type: 'special'` 与 `effect: 'KungWang'`。牌池抽牌函数中预留 `specialCardDrawn` 事件拦截器，以直接接管 TurnFlow 回合流。

---

### 4.5 手牌管理系统 (Hand Management)
-   **手牌格子**：固定 3 格。
-   **买入限制**：当 3 格满时，买入按钮置灰，玩家必须先执行卖出释放仓位。
-   **卡牌状态记录**：每张手牌持仓时必须记录：
    ```typescript
    interface HandSlot {
      card: JiaziCard;       // 卡牌原始数据
      buyScore: number;      // 买入时的评分
      leverage: number;      // 买入当回合的杠杆倍数（1.0 = 无杠杆）
      buyRound: number;      // 买入回合数（1-60）
      holdEarnings: number;  // 累计产生的持仓收益分
    }
    ```

## 5. 盈亏计算与杠杆爆仓公式 (Formulas & Edge Cases)

所有具体的得分与强平规则，在此处统一定义为唯一标准的数学表达：

### 5.1 卡牌当季评分公式 (calcCardScore)
每回合结算时，每张卡牌的当季评分由天干分值与地支藏干加权汇总得出：

$$\text{CardScore} = S_{\text{TianGan}} + W_{\text{CangGan}} \times \sum (W_{\text{Branch}} \times S_{\text{Branch}})$$

| 符号 | 类型 | 范围 | 说明 |
| :--- | :--- | :--- | :--- |
| $S_{\text{TianGan}}$ | float | $\{-3.0, -1.0, +0.5, +2.0, +4.0\}$ | 天干所对应的季节评分值 |
| $W_{\text{CangGan}}$ | float | $0.5$ (固定) | 地支藏干的总影响权重系数 |
| $W_{\text{Branch}}$ | float | $0.0 \sim 1.0$ (和为1.0) | 对应地支的藏干分布比例（取决于地支的本气、中气、余气） |
| $S_{\text{Branch}}$ | float | $\{-3.0, -1.0, +0.5, +2.0, +4.0\}$ | 地支藏干各气所对应的季节评分值 |
| $\text{CardScore}$ | float | $-6.0 \sim +6.0$ | 卡牌最终评分 |

#### 评分对应表 (四档制)
- **当季属性**（如春季持木牌）：**+4.0**
- **同组属性**（如夏季持木牌）：**+2.0**
- **稳定属性**（土属性）：**+0.5**
- **跨组属性**（如冬季持木牌）：**-1.0**
- **对立属性**（如秋季持木牌）：**-3.0**

---

### 5.2 收益计算公式

#### 5.2.1 每回合持仓收益 (settleHoldScore)
手牌中每张牌每回合自动产生的盈亏得分：

$$\text{HoldEarning} = \text{HOLD\_BONUS}(1.2) \times \text{CardScore} \times \text{Leverage}$$

#### 5.2.2 卖出得分 (settleSellScore)
卖出时基于买卖差价结算的一次性得分：

$$\text{SellScore} = \left( \text{SELL\_BASE}(8.0) + (\text{SellScore}_{\text{current}} - \text{BuyScore}) \times \text{SPREAD\_MULTIPLIER}(4.0) \right) \times \text{Leverage}$$

> **设计意图**：玩家在低评分（非当季，便宜）买入，高评分（当季，昂贵）卖出，利用差价实现得分爆发。

---

### 5.3 杠杆倍率与爆仓强平 (Leverage & Margin Call)

#### 5.3.1 杠杆倍率表 (季节推进表)
买入卡牌时可开启杠杆。杠杆倍数由买入时**卡牌当前所在季节的进度回合**决定：
- 季节第 1-3 回合：**1.0x** (无杠杆)
- 季节第 4-6 回合：**1.5x**
- 季节第 7-9 回合：**2.0x**
- 季节第 10-11 回合：**2.5x**
- 季节第 12 回合：**3.0x** (换季前夕，最高倍数，最高利息)
*注意：买入时的杠杆倍数一旦被标记，在卡牌持仓全生命周期内固定不变，不受后续季节更替重置的影响。*

#### 5.3.2 爆仓强平时序与规则
每回合开始持仓扣气后，系统自动检查爆仓阈值：

$$\text{CheckMarginCall} \implies \text{CurrentQi} \le 0$$

1.  **强平执行**：
    若气归零且持有杠杆牌，系统随机强行卖出（平仓）手牌中的 1 张杠杆牌。
2.  **强平收益结算**：
    被强平的卡牌**计算并计入卖出得分，若卖出得分大于 0 则施加 80% 折价惩罚，负收益（亏损）则 100% 承担以防赖账**。调用 `settleForcedSell`。
3.  **强平无额外惩罚**：
    强平**不扣减 3 点卖出气**（视为 0 气消耗卖出），亦无额外的分数追加罚分。
4.  **强平循环与停止 edge case**：
    *   若强平 1 张牌后，气仍然为 0 且手牌中还有其他杠杆牌，系统将继续强平第 2 张，直到气 > 0 或手牌中无任何杠杆牌。
    *   **⚠️ 边界跳转**：若全部杠杆牌强平完毕后，当前气仍然为 0（手牌中仅剩下无杠杆普通牌或为空），**强平停止，剩余普通牌予以保留**。此时由于气为 0 且无杠杆，玩家无法进行任何消耗气的操作，在接下来的玩家操作回合**被迫只能选择“等待”**以回复气（普通牌正常计算盈亏与气耗）。

## 6. UI 与表现规范 (UI & Presentation Specs)

-   **分辨率基准**：428x760 (垂直流，手机 H5 优先)，要求在 375px 以上设备自适应。
-   **美术基准风格**：东方水墨 / 国风简约几何风格。配合五行标志的色彩变动。
-   **微动效要求**：
    *   **买入卡牌**：卡牌从公共展示区以 Tween 缩放飞入对应手牌格；
    *   **季节更替**：全屏一层半透明淡入淡出水墨晕染，文字震动“春去夏来”；
    *   **爆仓警告**：气槽发出红色闪烁光环，被强平牌发生燃烧消散效果，弹出大红字“强平！”提示。

## 7. 核心调参旋钮表 (Tuning Knobs)

所有核心平衡参数均在 `src/data/constants.ts` 中声明，可通过外部配置一键调优：

| 参数名称 | 默认值 | 类别 | 调优影响 |
| :--- | :--- | :--- | :--- |
| `MAX_QI` | 80 | 门槛 (Gate) | 控制持仓上限的紧迫感 |
| `QR` (自然回气) | 7 | 效率 (Feel) | 基础回气速度 |
| `WR` (等待额外回气) | 10 | 效率 (Feel) | 等待对玩家的吸引力 |
| `CB` (基础买入消耗) | 11 | 效率 (Feel) | 建立基础资源吞吐价值 |
| `CS` (卖出即时回气) | 9 | 效率 (Feel) | 短线流动性的周转效率 |
| `LQC` (杠杆固定消耗) | 10 | 效率 (Feel) | 开启杠杆的前置门槛门票 |
| `HOLD_BONUS` | 1.2 | 曲线 (Curve) | 持仓的长线整体收益效率 |
| `SELL_BASE` | 8.0 | 曲线 (Curve) | 卖出得分保底底薪 |
| `SPREAD_MULTIPLIER`| 4.0 | 曲线 (Curve) | 短线差价博弈的收益敏感度 |
| `CANG_GAN_WEIGHT` | 0.5 | 曲线 (Curve) | 地支藏干对卡牌强度的影响比重 |
