# 气资源系统

> 状态：Draft
> 层级：Foundation
> 优先级：MVP

## 概述

管理玩家的气资源——游戏中唯一的交易筹码。气的回复和消耗构成"等 vs 动"的核心博弈，是连接玩家决策与分数产出的桥梁。

## 玩家体验

玩家每回合都在感受气的压力：想操作但气不够，想等回气但又怕错过好牌。气是有限的，每一次花出去都要想清楚值不值。

## 详细规则

### 气的基本属性

| 属性 | 规则 |
|------|------|
| 可用气上限 | 动态可用气上限：$currentMaxQi = 80 - totalLockedQi$（被手牌卡牌锁定的保证金之和） |
| 初始值 | 50 |
| 可否超出上限 | 不可以，自然回复、等待回复和卖出退还均受限于 $currentMaxQi$ |
| 最低值 | 0（归零或负数时触发爆仓强平） |

### 气的回复

| 条件 | 规则 |
|------|------|
| 上回合选择"等待" | 回复 WR(10) + QR(7) = 17 点 |
| 上回合执行了买入/卖出 | 自然回复 QR(7) 点 |
| 回复可以超过上限 | 不可以，封顶为当前动态可用气上限 $currentMaxQi$ |

> 设计意图：鼓励玩家在气少、持仓气耗较重时有意识地选择等待。连续买入会快速消耗可用气，并大幅压低可用气上限，被迫等待。

### 气的消耗与资金/保证金流转

为了使“气”具备可用流动性与保证金语义，手牌成为玩家的“仓位”，本系统采用仓位与保证金流转模型：

| 操作 | 消耗与流转逻辑 |
|------|---------|
| **买入消耗** | 总买入消耗为 $buyCost = CB(11) \times (1 + 0.05 \times 评分) [+ LQC(14)]$。买入时将其拆分为：<br>1. **买入手续费 (Entry Fee)**：固定为 2 气，永久消耗，不予退还。<br>2. **锁定保证金 (Locked Qi)**：$lockedQi = buyCost - 2$，暂时锁入仓位。可用气上限被压低。 |
| **持仓气耗** | 基于卡牌强度动态计算 $max(0.5, 1.5 + 0.4 \times 当季评分) \times 杠杆倍数$，每回合结算时扣除，允许扣成负数。 |
| **卖出返还** | 卖出卡牌时释放对应的 $lockedQi$ 保证金，并根据卖出分数进行修正，再扣除卖出气耗 4 气：<br>$\text{sellQiReturn} = lockedQi + \text{clamp}(sellScore \times 0.2, -8, +8) - 4$<br>若 $sellQiReturn < 0$ (亏损严重导致保证金被扣完)，则该操作为净损耗。 |
| **爆仓强平** | 当结算后可用气低于或等于 0 时，触发爆仓强平。随机强平一张杠杆卡牌。 |

#### 保证金与流动性计算实例

1. **加杠杆买入评分 1.0 的卡牌**：
   - 总买入消耗为 $\lceil 11 \times (1 + 0.05 \times 1.0) \rceil + 14 = 12 + 14 = 26$ 气。
   - 消耗可用气 26，其中手续费 2 气，锁定保证金 $lockedQi = 24$ 气。
   - 动态可用气上限降为 $80 - 24 = 56$ 气。
2. **卖出该卡牌（卖出积分 $sellScore = 15$）**：
   - 获得积分 $15$。
   - 返还保证金修正量为 $\text{clamp}(15 \times 0.2, -8, +8) = +3$ 气。
   - 卖出实得气为 $24 + 3 - 4 = 23$ 气。
   - 可用气上限恢复加回 24，重置为 80。
3. **卖出该卡牌（严重亏损，卖出积分 $sellScore = -25$）**：
   - 扣除/增加积分 $-25$。
   - 返还保证金修正量为 $\text{clamp}(-25 \times 0.2, -8, +8) = -5$ 气。
   - 卖出实得气为 $24 - 5 - 4 = 15$ 气。
   - 可用气上限加回 24，重置为 80。

#### 蛰伏低耗机制（Taichi Low-Cost Settle）

持仓气耗公式为 $max(0.5, 1.5 + 0.4 \times 当季评分) \times 杠杆倍数$。当卡牌处于非当季/对立季节时，当季评分会跌为负数（如对立季节评分为 -3），计算得出 $1.5 + 0.4 \times (-3) = 0.3$，此时触发公式中 $max(0.5)$ 的保底拦截，使得持仓气耗仅为 $0.5 \times 杠杆倍数$。

*设计意图*：这属于有意的**蛰伏设计**，鼓励玩家在卡牌亏损的“寒冬”期以极低的气耗成本进行扛仓持有，以等待换季评分反弹，体现五行轮转、蛰伏蓄势的特色玩法。

#### 气不足与阻断校验

| 场景 | 处理方式 |
|------|----------|
| 可用气不足以支付买入成本 | 买入置灰/阻断，无法执行买入。 |
| 卖出净变化为负且可用气不足 | 当 $\text{sellQiReturn} < 0$ 且 $\text{可用气} < |sellQiReturn|$ 时，说明剩余可用气不足以支付卖出带来的净损耗，**阻断卖出操作**，防止玩家通过卖出非法透支。玩家必须执行等待或通过其他能带来正回气的卡牌平仓来脱困。 |

#### 强平与 Option B 双保险低保机制

当结算后玩家可用气归零或为负数（且手牌中持有杠杆卡牌）时，触发爆仓强平：
1. **先释放保证金**：从手牌中随机移除一张杠杆卡牌，优先退回其保证金的 $50\%$：$\text{forcedLiquidationQiReturn} = \lfloor lockedQi \times 0.5 \rfloor$。
2. **应用上限更新**：将该卡牌从手牌中移除，加回对应的可用气上限 $currentMaxQi = 80 - \text{newTotalLocked}$。
3. **双保险低保恢复与上限截断**：将当前气与强平返还加总后，执行低保恢复并进行上限截断：
   $$newQi = \min(\max(qi + \text{forcedLiquidationQiReturn}, 10), currentMaxQi)$$
   强平后打断连环强平，提供 10 气（或当前上限截断值）的财务垫，允许玩家在下回合挣扎或等待。
4. **强平分数罚扣**：强平卡牌正常获得卖出分数，但正收益打 8 折，且扣罚 35 分作为强平违约金。

## 经济流转与公式

### 回复公式

每回合开始时（在结算扣气和强平之后）：
```
totalLockedQi = 遍历手牌 slot.lockedQi 之和
currentMaxQi = 80 - totalLockedQi
当前气 = min(currentMaxQi, 当前气 + QR(7))  // 自然回复

如果 上回合动作 == "等待":
    当前气 = min(currentMaxQi, 当前气 + WR(10))  // 额外等待回气
```

### 买入消耗与保证金流转公式

```
buyCost = calculateBuyCost(bestCardScore, useLeverage)
如果 当前气 < buyCost:
    买入阻断，提示气不足
否则:
    当前气 -= buyCost
    entryFee = 2 (固定扣除)
    lockedQi = buyCost - 2 (锁入卡牌)
    手牌 slot 初始化，记录其 lockedQi 保证金
    totalLockedQi 更新，可用气上限 currentMaxQi 降低
```

### 卖出消耗与保证金流转公式

```
slot = 手牌对应插槽
sellScore = calculateSellScore(currentScore, slot.buyScore, slot.leverage)
sellQiReturn = slot.lockedQi + clamp(sellScore * 0.2, -8, 8) - 4

如果 sellQiReturn < 0 且 当前气 < abs(sellQiReturn):
    卖出阻断，提示可用气不足以支付净损耗
否则:
    手牌 slot 移除，加回对应的可用气上限
    如果 sellQiReturn >= 0:
        当前气 = min(currentMaxQi, 当前气 + sellQiReturn)
    否则:
        当前气 -= abs(sellQiReturn)
    增加积分 = sellScore
```

## 边界情况

| 场景 | 处理方式 |
|------|----------|
| 气为 0 且无杠杆牌 | 只能等待，买入/卖出置灰。普通持仓无爆仓风险，下回合被迫等待以恢复气。 |
| 气为 0 且持有杠杆牌 | 触发爆仓强平：先加回上限并释放 $50\%$ 保证金，再在上限内截断恢复 10 气低保缓冲。 |
| 保证金溢出/截断 | 当持有的保证金极多（如持有 $2$ 张强杠杆牌锁定了 $50$ 气，上限降为 $30$），气在恢复或卖出加回时，绝对不可以突破当前可用上限 $currentMaxQi$。 |

## 依赖关系

| 系统 | 方向 | 性质 |
|------|------|------|
| 干支卡牌数据 | 依赖 | 读取牌的主属性计算买入系数 |
| 季节循环 | 依赖 | 读取当前季节计算买入系数 |
| 公共牌池 | 被依赖 | 判断玩家是否有足够气买入 |
| 手牌管理 | 双向依赖 | 提供买入/卖出/持仓气耗的实时气量消耗检查与扣除 |
| UI 渲染 | 被依赖 | 展示气条、消耗预估 |

## 调参旋钮

> ⚠️ 以下数值为初始占位，需跑模拟测试后调整。

| 参数 | 占位值 | 安全范围 | 影响 |
|------|--------|----------|------|
| QR（每回合自然回复） | 7 | 5 ~ 10 | 基础回气速度 |
| WR（等待额外回复） | 10 | 5 ~ 15 | 等待的吸引力 |
| CB（买入基础消耗） | 12 | 8 ~ 20 | 所有买入的基数 |
| 卖出消耗 | 4 | 1 ~ 5 | 卖出成本 |
| CS（卖出回气） | 0 | 0 ~ 12 | 卖出的气补偿 |
| LQC（杠杆额外消耗） | 14 | 5 ~ 15 | 杠杆买入的固定额外代价 |
| HOLD_QI_COST（持仓气耗公式） | max(0.5, 1.5+0.4×评分) | 1 ~ 5 | 持有卡牌的每回合气成本（×杠杆倍数），评分越高气耗越大 |

### 调参参考指标

| 指标 | 目标 |
|------|------|
| 一局总可等待回合数 | 20-30 回合（玩家不能全程等） |
| 一局总可操作次数 | 15-25 次 |
| 全等待 vs 全操作的差距 | 操作得当的玩家得分应明显高于全等待者 |
| 气竭（被迫等待）频率 | 平均每 3-5 回合出现一次 |

## 验收标准

- [ ] 气上限 80，初始 50，不可超出
- [ ] 等待回合额外回复 WR(10) 气
- [ ] 每回合自然回复 QR(7) 气（不管上回合操作是什么）
- [ ] 卖出回复 CS(0) 气
- [ ] 买入消耗根据评分公式正确计算
- [ ] 杠杆买入额外消耗 LQC(14)，不乘杠杆倍数
- [ ] 持仓气耗 = HOLD_QI_COST × 杠杆倍数（每回合每张牌）
- [ ] 气归零时触发爆仓（每次最多平仓一张，且提供低保气值恢复缓冲）
- [ ] 气不足时对应操作不可执行
- [ ] 气为 0 时只能等待
- [ ] 所有消耗参数可通过配置文件调整
