# 季节循环系统

> 状态：Draft
> 层级：Foundation
> 优先级：MVP

## 概述

管理春夏秋冬四季的循环流转，每个季节持续 3-12 个随机回合。季节与五行属性共同决定气→分数的转化效率，是游戏经济系统的核心驱动。

## 玩家体验

玩家感受到季节的呼吸感——春天来了，木牌开始涨；夏天来了，火牌接力。好的玩家能预判季节切换的节奏，提前布局，在效率最高的窗口集中操作。

## 详细规则

### 杠杆乘数表（表B — 季节递增）

杠杆倍数随当前季节内已进行的回合数递增，创造择时博弈空间：

| 季节内回合 | 杠杆倍数 | 说明 |
|-----------|---------|------|
| 第 1-3 回合 | 1.0x | 无杠杆，安全期 |
| 第 4-6 回合 | 1.5x | 轻度杠杆 |
| 第 7-9 回合 | 2.0x | 中度杠杆 |
| 第 10-11 回合 | 2.5x | 较高杠杆 |
| 第 12 回合 | 3.0x | 最高杠杆（季节末尾，换季风险最大） |

> 设计意图：季节早期杠杆低但安全，晚期杠杆高但换季风险大。追涨杀跌型玩家在早期低杠杆买入赚快钱，长期持有者不会使用杠杆（持仓气耗 × 倍数太高）。

### 四季与五行的圆盘模型

```
          春(木)
        生长 / 萌芽
            ↓
夏(火) 显化 / 传播 → 秋(金) 收敛 / 成形
            ↑
        冬(水)
      汇聚 / 收藏

  土 = 太极点 / 承载器 / 环境镜像
```

### 季节作为环境场

季节不是简单的属性加成，而是世界当前的能量场。五行在不同季节中显现不同状态，没有绝对好坏，只有是否顺势、是否费力、是否适合当下选择。

| 季节 | 环境状态 | 支持的行为 | 风险 |
|------|----------|------------|------|
| 春(木) | 生长、萌芽、发展、有方向性 | 布局、扩张、从低位启动 | 方向错时成长受阻 |
| 夏(火) | 显化、传播、爆发、变化 | 短线爆发、让价值被看见 | 消耗快，容易过热 |
| 秋(金) | 收敛、下降、冷却、成形 | 兑现、回收、落袋、定价 | 过早收缩会压制成长 |
| 冬(水) | 聚集、收藏、蓄势、等待 | 积累、低位储备、等待新周期 | 当前收益不明显 |
| 土 | 太极点、承载、调和 | 承接环境、稳定状态、显出旺气 | 缺少外部方向时平庸 |

### 季节与牌面状态

同一张牌由天干、地支、藏干共同构成。季节只提供外部环境，真正的当下状态由 [system-scoring.md](file:///d:/works/jiazi-game/design/gdd/system-scoring.md) 中的共振评分模型计算：

```
牌面状态 = 天干主动能量 × 当前季节
        + 地支藏干根基 × 当前季节
        + 天干地支内部关系
```

这意味着：

- 木牌不等于永远只在春天好；如果地支藏水，冬天可能有蓄势价值。
- 火牌不等于永远只在夏天好；如果根基受水压制，夏天也可能高收益高风险。
- 金牌代表收敛和兑现，不是单纯负面下跌。
- 水牌代表汇聚和收藏，不是单纯停滞。
- 土牌不再因四季无土而失去状态，而是随环境显性并承载其他气。

### 季节流转

- 顺序固定：春 → 夏 → 秋 → 冬 → 春 → ...
- 每个季节持续 **3-12 回合**，游戏开始时随机生成每个季节的长度
- 季节进度对玩家**不完全可见**（只显示"当前第几回合"，**隐藏本季总回合数**，保持对换季时机的未知感）
- 季节切换时，UI 明确提示玩家

### 核心框架：气→分数转化效率

所有得分操作的本质都是**气转化成分数**，转化效率由牌面状态决定：

```
效率 = 状态得势程度 × (1 + 干支关系修正 + 杠杆修正)
```

**两种转化方式：**

| 方式 | 气消耗 | 分数产出 | 特点 |
|------|--------|---------|------|
| 持仓收益 | 买入时消耗一次 | 每回合持续结算 | 长线，省气，靠时间积累 |
| 卖出收益 | 买入+卖出消耗两次 | 卖出时一次性结算 | 短线，费气，集中爆发 |

### 整局资源模型（待跑测调参）

```
一局 60 回合
气上限 80
气回复速度：每回合 QR(7)，等待额外 WR(10)
买入消耗：CB(12) × (1 + 0.05 × 评分) [+ LQC(10) 杠杆]
卖出消耗：固定 3 气
持仓气耗：max(0.5, 1.5 + 0.4 × 评分) × 杠杆倍数

→ 整局大约能操作 N 次
→ 每次操作平均转化 M 分
→ 目标总分区间：在评分模型实现后通过模拟确定
```

## 公式

### 盈亏与资源转化公式（规范引用）

季节对游戏资源（气与分数）转化效率的控制，本质上是通过**改变卡牌在不同季节下的“当季评分”**实现的。为了避免公式版本脱节，本系统所有具体的盈亏计算公式均引用 [system-scoring.md](file:///d:/works/jiazi-game/design/gdd/system-scoring.md)。

主要计算逻辑如下：

1. **当季评分生成**：
   卡牌的“评分”每回合根据当前季节实时计算，参见 [system-scoring.md - 天干地支共振评分模型](file:///d:/works/jiazi-game/design/gdd/system-scoring.md)。评分由天干主动能量、地支藏干根基与干支内部关系共同生成。季节提供外部环境场，土作为太极承载点随环境显性。

2. **持仓收益（每回合自动）**：
   `每回合持仓盈亏 = HOLD_BONUS(1.2) * 当季评分 * 杠杆倍数`。具体参见 [system-scoring.md - 持仓结算](file:///d:/works/jiazi-game/design/gdd/system-scoring.md#L33-L44)。

3. **卖出收益（一次性）**：
   `卖出得分 = (SELL_BASE(8) + (卖出评分 - 买入评分) * SPREAD_MULTIPLIER(4)) * 杠杆倍数`。具体参见 [system-scoring.md - 卖出结算](file:///d:/works/jiazi-game/design/gdd/system-scoring.md#L48-L56)。

4. **气资源消耗**：
   卡牌的买入气消耗、持仓气耗和卖出气消耗，具体公式参见 [system-qi-resource.md - 气的消耗](file:///d:/works/jiazi-game/design/gdd/system-qi-resource.md#L36-L77)。


## 边界情况

| 场景 | 处理方式 |
|------|----------|
| 一个季节只有 3 回合就结束了 | 玩家来不及布局，体现随机性风险 |
| 一个季节持续 12 回合 | 长线策略收益最大化，但要注意别错过下季 |
| 连续短季节（3+3+3+3） | 短线策略优势，持仓收益累计少 |
| 连续长季节（12+12+12+12） | 长线策略优势，季节可预测性强 |
| 游戏结束时恰好是某季中途 | 持仓牌正常结算最后一回合 |
| 60 回合不在季节边界结束 | 正常，季节在第 60 回合自然中断 |

## 调参旋钮

> ⚠️ 以下数值为设计目标。具体实现前需与 `system-scoring.md` 的共振评分模型保持一致。

| 参数 | 设计值 | 安全范围 | 影响 |
|------|--------|----------|------|
| 天干权重 | 0.6 | 0.5 ~ 0.75 | 主动能量对总评分的影响 |
| 地支藏干权重 | 0.3 | 0.2 ~ 0.4 | 根基与容器对总评分的影响 |
| 干支关系权重 | 0.1 | 0.05 ~ 0.2 | 内部顺逆对总评分的影响 |
| 土环境镜像强度 | 0.5 | 0.3 ~ 0.8 | 土承接当前旺气的幅度 |
| 季节长度范围 | 3-12 | 3-12 | 控制不确定性 |
| 状态分基础范围 | -4 ~ +4 | -5 ~ +5 | 单层五行在季节场中的基础状态 |

## 验收标准

- [ ] 春→夏→秋→冬循环正确，顺序不乱
- [ ] 每季 3-12 回合随机生成，游戏开始时确定
- [ ] 季节进度可见（仅显示当前回合，隐去总回合）
- [ ] 季节切换有明确提示
- [ ] 季节语义正确表达木生发、火显化、金收敛、水汇聚
- [ ] 土作为太极承载点，不再因四季无土而频繁失去状态
- [ ] 季节评分引用天干地支共振模型，而不是孤立的四档属性表
- [ ] 所有评分权重参数可通过配置文件调整，无需改代码
