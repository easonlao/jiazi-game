## Note

Phaser 3.90.0 was released on 2025-05-23, near the LLM knowledge cutoff (May 2025). Phaser 4.0.0 was released on 2026-04-10, which is beyond training data. This project uses Phaser 3, but be aware that some Phaser 4 changes may appear in documentation.

## Post-Cutoff Changes (v3.90.0)

- Rounded corner support for Rectangle Shape Game Objects (`setRounded()`)
- Firefox fallback for positional audio
- Multiple stability fixes (physics, text rendering)

## Migration from earlier Phaser 3 versions

No breaking changes between v3.80+ and v3.90.
